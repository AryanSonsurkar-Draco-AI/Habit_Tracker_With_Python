# Habit_Tracker_With_Python

A simple command-line based Habit Tracker built using Python.
This project allows user to add habits, track them daily, and store data persistently using JSON file.

The goal of this project is to understand basic data storage, file handling, and logic building in Python.

---

## Features
- Add new habits
- View all saved habits
- Mark habits as completed
- Store habit data permanently using JSON
- Begineer-friendly and easy to modify
- No external libraries used

---

## Concepts Used
- Functions
- Dictionaries
- JSON file handling (read and write)
- Conditional statements
- Basic CLI menu system

## How to Run
1. Make sure Python is installed on your system.
2. Open terminal / command prompt in the project folder.
3. Run the program using:
```bash
python tracker.py 
```

---

## How it works
- Habits are stored in JSON file (habits.json)
- Each habit has a name and completion status
- Data is loaded when the program starts 
- Data is saved automatically after every change
